# CapyFlow 0.4.11

- Personal collection entries stay linked to the owner's collaborative playlist, including collaborator additions, removals and renames.
- Add songs directly inside personal and shared playlists using YouTube Music search and recently played songs.
- Add the current song to a playlist from Now Playing's menu.
- Collaborator management shows profile photos, names, usernames, roles and removal confirmation.
- Message banners have an opaque dark background. Outgoing messages show Sending, Sent and Read receipts.
- Includes the message banner dependency fix for launch and sheet presentation.
- Preserves existing playback, downloads, lyrics, queue, account backups and streaming configuration.

Install the signed update over the existing app using the same bundle identifier and signing identity to retain local data.

CapyFlow 0.4.11 · Build 18 is available through Sidebar → Updates → Check for updates. The IPA requires signing before installation.
