CapyFlow 0.4.10 · Build 17

- Home now keeps Friends & shared playlists clear of the music controller, with clearance that follows the dock height.
- Added CapyFlow app information, installed version/build number, and “by Seph” at the bottom of Home and Settings.
- Includes private real-time messaging, account-saved conversations, unread indicators, and smooth purple in-app message banners.
- Includes account playlist backup and the shared-playlist removal fixes from the preceding builds.

This is the first published stable iOS release. Older installed CapyFlow builds can detect it under Sidebar → Updates → Check for updates.

The IPA is unsigned. Sign it using your usual KravaSign or Sideloadly setup, keep the same app bundle identifier, and install over the existing CapyFlow app. Update opens this release page; it does not automatically install the app. There are no Apple push notifications.
